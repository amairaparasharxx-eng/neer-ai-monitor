# Dataset
The application downloads water_quality.csv automatically on first launch.

Source mirror:
https://github.com/sudesokin/Water-Quality-Analysis-and-Forecasting/blob/main/dataset/water_potability.csv

The dataset contains historical sample measurements and a binary potability label. Review its provenance and terms before formal research use.

Neer's current model uses ph, Solids, Conductivity and Turbidity. The original column name Solids is preserved; it is not presented as a direct TDS sensor reading.
